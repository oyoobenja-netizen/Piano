 Simple Piano Design
 About the Project

This project is a simple piano design created using HTML and CSS only. It demonstrates how to build a visual piano keyboard using basic HTML elements and CSS styling, without using JavaScript or any external libraries.

 Features
Clean and simple piano keyboard design.
White and black piano keys.
Styled using CSS.
Built with basic HTML structure.
No JavaScript has been employed
its a beginner-friendly project for practicing HTML and CSS.
 Technologies Used
HTML – To structure the piano keyboard.
CSS – To style the piano keys and create the piano design.
